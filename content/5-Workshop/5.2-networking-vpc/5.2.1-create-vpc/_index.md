1. In the search bar, type **VPC** and select **Your VPCs** → **Create VPC**.
2. Select **VPC only**, name it `my-project-vpc`, IPv4 CIDR: `10.0.0.0/16`.

   ![Create VPC my-project-vpc](/images/5/5.2.1/01-vpc.png?classes=border,shadow)

   * **Result**: VPC ID `vpc-0b489eb298393e445`.
